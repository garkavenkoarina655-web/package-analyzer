# Анализатор пакетов (Package Analyzer)

Учебный проект по дисциплине "Конфигурационное управление".

Программа представляет собой консольный прототип для анализа пакетов.
На данный момент реализован разбор параметров командной строки и извлечение прямых зависимостей из файла Cargo.toml (формат Rust).

## Функции и настройки

### Функции

- `parse_arguments()` — разбирает аргументы командной строки с помощью модуля `argparse`.
- `parse_cargo_dependencies(file_path)` — читает файл `Cargo.toml` и возвращает список прямых зависимостей.
- `main()` — точка входа, выводит параметры и результаты анализа.

### Параметры командной строки

- `--package` — Имя анализируемого пакета (например, `requests`).
- `--repo` — URL-адрес репозитория или путь к файлу тестового репозитория (например, `Cargo.toml`).
- `--mode` — Режим работы с тестовым репозиторием. Доступные значения: `test` или `prod`.
- `--version` — Версия пакета (например, `2.31.0`).
- `--filter` — Поддержка для фильтрации пакетов (например, `>=1.0`).
- `-h, --help` — Справка по использованию.
