- [x] Этап 3 — Основные операции

## Описание функций
- parse_arguments() — разбор аргументов (argparse).
- read_file_safely(file_path) — безопасное чтение файла.
- parse_cargo_dependencies(file_path) — поиск зависимостей в Cargo.toml.
- parse_cargo_lock(file_path) — построение графа из Cargo.lock.
- bfs_recursive(...) — рекурсивный обход графа (BFS).
- process_cargo(...) — запуск анализа Cargo.
- main() — точка входа.

## Параметры
--package, --repo, --mode (test/prod), --version, --filter, -h.

## Запуск
Требования: Python 3.10+.
Команда для запуска: python src/main.py --package my_app --repo "Cargo.lock" --filter "test"

## Этап 1: Минимальный прототип
Цель: Прием параметров через командную строку и вывод в формате ключ-значение.
Реализация: Модуль argparse, 5 параметров, встроенная обработка ошибок (например, --mode принимает только test/prod).
Пример вывода:
Пакет: requests
Файл: Cargo.toml
Фильтр: None

## Этап 2: Сбор данных
Цель: Извлечение прямых зависимостей из Cargo.toml.
Реализация: Функция parse_cargo_dependencies ищет секцию [dependencies] и берет имена пакетов до знака =.
Пример вывода:
Анализ из файла: Cargo.toml
Прямые зависимости:
- serde
- tokio

## Этап 3: Основные операции
Цель: Построение графа зависимостей (с транзитивностью) и обход BFS с рекурсией.
Реализация: Функция parse_cargo_lock строит граф из Cargo.lock. Рекурсивный bfs_recursive ищет все зависимости. Работает фильтр по подстроке (--filter) и защита от циклов (visited).
Пример вывода:
Анализ файла: Cargo.lock
Транзитивные зависимости my_app:
- my_app
- serde
- serde_derive
